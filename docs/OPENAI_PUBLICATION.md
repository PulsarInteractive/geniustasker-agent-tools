# Official directory publication

A working custom connector is not an approved directory listing. Submission and publication are separate owner-controlled steps.

1. Verify the publishing identity **Pulsar Interactive** in the OpenAI organization and assign the appropriate submission permissions.
2. Prepare a plugin ZIP with the remote MCP declaration, public metadata and relevant skills. Keep credentials, backend code and private instructions outside it.
3. Upload a draft, verify the MCP domain using the challenge provided by OpenAI, connect a dedicated demonstration account and resolve the automated findings.
4. Supply reproducible positive and negative scenarios, a walkthrough recording and release notes. The demo account must contain synthetic data and remain usable for review. Do not provide your personal account.
5. Submit the draft and required attestations. After approval, choose when to publish. Approval and its timing belong to OpenAI.

Before submission, ensure support, privacy and legal URLs are reachable by reviewers, describe the actual data handled, and match the publisher. Review write/destructive annotations, revocation, least-privilege grants, subscription restrictions and safe retries. Do not advertise availability in the directory before approval and publication.

The private preview websites remain protected. Their current protection must be deliberately reconciled with reviewer access before public submission; it is not removed by installing the connector.
